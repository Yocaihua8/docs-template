专门记录**对外 API 的兼容性变化与迁移指南**，面向接口使用方（前端、第三方、合作方）。

## 1. 与其他文档的区别

| 文档 | 面向 | 粒度 | 关注点 |
|------|------|------|--------|
| `../../CHANGELOG.md` | 全体使用者/维护者 | 版本整体变更 | 结果 |
| `api-spec.md` | API 使用方 + 实现方 | 当前接口契约 | **权威源**：字段、错误码、响应结构 |
| `api-changes.md`（本文件） | API 使用方 | 单个接口 × 版本 | 迁移方式、兼容策略、弃用时间 |

**职责切分**：接口**契约**以 `api-spec.md` 为权威；接口**变更与迁移**以本文件为权威。两者互相引用，不重复写对方的内容。

## 2. 变更分级

| 级别 | 定义 | 举例 | 处置 |
|------|------|------|------|
| **Breaking** | 使调用方必须修改才能工作 | 删除字段、改类型、改语义 | 必须提前通知 + 版本号升主版本 |
| **Compat** | 使调用方不修改也能工作 | 新增可选字段、新增接口 | 小版本即可 |
| **Internal** | 不影响调用方 | 响应体内部顺序调整 | 仅内部记录 |

## 3. 变更规则

- 破坏性变更**必须**走 ADR 记录决策原因，并在本表注明 ADR 编号
- 弃用接口**必须**保留至少一个次版本周期并注明下线时间
- 新增字段**应该**使用可选类型，避免调用方校验失败
- 所有变更**必须**在相关接口文档里同步更新示例
