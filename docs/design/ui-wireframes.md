## 附录：填写示例

### 示例 1：页面线框图

#### 页面名称

任务中心

#### 页面目标

帮助运营人员快速筛选任务、查看详情并执行处理动作。

#### 布局结构

```text
[顶部区域]
[左区：任务分类 / 状态筛选]
[中区：任务列表]
[右区：任务详情 / 操作按钮]
```

#### 关键组件

- 左侧状态筛选栏、中间任务表格（含分页与搜索）、右侧详情与审批操作栏

#### 关键交互

1. 点击左侧状态分类，中区重新拉取对应任务列表并重置页码。
2. 选中列表行，右区展示任务详情与处理记录。
3. 点击“审核通过 / 驳回”弹出确认框，提交后刷新当前列表项状态。

#### 空状态 / 异常状态

- 空状态：提示“当前筛选条件下暂无任务”，提供“重置筛选”按钮。
- 加载状态：中区与右区显示骨架屏，禁用重复提交按钮。
- 错误状态：顶部提示错误信息并提供“重试”操作。
