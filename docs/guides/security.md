## 1. 强制基线

以下要求**必须**在所有项目中落实：

- [ ] 任何密钥、Token、数据库密码**禁止**入库，使用环境变量或密钥管理服务
- [ ] 用户密码**必须**使用 bcrypt / argon2 等慢哈希，禁止 MD5/SHA1
- [ ] 对外接口**必须**强制 HTTPS
- [ ] 所有鉴权接口**必须**记录成功/失败日志
- [ ] 依赖**应该**定期扫描（如 `npm audit`、`pip-audit`、Dependabot）

## 5. 上线前安全自查

- [ ] 代码无硬编码凭证（grep / git-secrets 检查）
- [ ] 依赖漏洞扫描通过
- [ ] 所有外部输入有校验
- [ ] SQL 使用参数化查询，前端输出已做 XSS 转义
- [ ] CORS 白名单明确，非通配符
- [ ] 生产环境关闭 debug、stacktrace 外泄
- [ ] 日志不含敏感数据（密码、Token、身份证）
