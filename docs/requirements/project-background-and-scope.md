```markdown
# 项目背景与范围

> 状态：Draft
> Owner：张三
> Last Updated：2026-04-18
> Scope：订单中心后台
> Related：`../design/system-design-overview.md`

## 1. 项目背景

当前运营同学主要通过 Excel 管理订单状态，人工更新慢且容易出错，需要一个统一的后台系统来完成订单查询、状态处理和导出。

## 2. 项目目标

### 2.1 业务目标
- 将订单处理时效从 2 小时缩短到 30 分钟内

### 2.2 用户目标
- 让运营同学可以按筛选条件快速查询和处理订单

### 2.3 技术目标
- 提供统一 API、可审计日志和可扩展导出能力

## 4. 项目范围

### 4.1 本期纳入范围
- 订单查询
- 订单状态更新
- 订单导出

### 4.2 本期不纳入范围
- 自动营销触达
- 移动端 App
```
