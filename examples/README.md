# 填好的示例项目

本目录展示**把模板填完是什么样子**。附录里的单片段示例回答不了"一份完整文档长啥样"的问题，本目录用一个虚构项目给出答案。

## 当前示例

| 目录 | 主题 | 覆盖文档 |
|------|------|----------|
| `order-service/` | 订单中心后台（虚构） | 需求背景、功能规格（订单导出） |

## 使用方式

1. 浏览 `order-service/` 中的文档，理解各字段"应该填成什么样"
2. 复制模板到你自己的项目，按相同口径填写
3. **不要**直接把本目录作为依赖引用 —— 它只用于阅读示范

## 扩展说明

示例刻意保持**最小可读**：只填了需求入口和 1 个功能文档。完整 8 份最低必填文档的样例属于后续迭代，跟踪在 `../docs/BACKLOG.md`。
