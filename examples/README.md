# 精简填写示例

本目录展示**一份活动文档填好后是什么样子**。这里用虚构项目给出内容深度和写作口径示范，不代表任何 profile 的完整生成结果。

## 当前示例

| 目录 | 主题 | 覆盖文档 |
|------|------|----------|
| `order-service/` | 订单中心后台（虚构） | 需求背景、功能规格（订单导出） |

## 使用方式

1. 浏览 `order-service/` 中的文档，理解各字段"应该填成什么样"
2. 使用根目录初始化器生成适合项目的 profile / pack，再按相同口径填写
3. **不要**直接把本目录作为依赖引用 —— 它只用于阅读示范

## 扩展说明

示例刻意保持**最小可读**：只填了需求入口和 1 个功能文档。若要查看 personal、commercial、open-source 三类项目实际会生成哪些文件，请在仓库根目录运行初始化器的 dry-run；最终文件集合以 `scaffold/` manifest 为准。
